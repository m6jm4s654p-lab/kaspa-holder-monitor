# KASPA Holder Monitor v2.0

## 主な更新

- 価格チャートを4時間足に固定
- 期間切り替えボタンを廃止
- CoinGeckoの約100日分の時間別価格を4時間単位へ集約し、直近30日分は公式4時間OHLCを優先
- チャートを横スクロールして過去データを確認可能
- 起動時と更新時は最新のローソク足を表示
- 「最新へ」ボタンでチャート右端へ移動
- 10MA・25MA・75MA・200MAと表示切り替えを継続
- 価格は60秒、チャートとMAは15分ごとに自動更新

## PC専用レイアウト

画面幅900px以上では、最大幅1400pxのPC用ダッシュボードへ自動的に切り替わります。価格チャートを中心に、アドレス数、Holder Trend Score、供給量、クジラ集中度、Holder分析、保有量別アドレス数、各種比較チャートを複数列で表示します。

900px未満では、従来のスマートフォン向け縦型レイアウトを維持します。

## データ方針

一般公開向けのネットワーク分析アプリです。個人の保有量、ウォレットアドレス、取得価格、損益、ポートフォリオ情報は取得・保存・表示しません。
