# KASPA Holder Monitor v2.2

## 主な更新

- BybitのKASUSDT無期限先物から現在のOI、24時間OI変化率、資金調達率を取得
- 価格・主要MA・OI・資金調達率・100K+アドレス動向を統合した「KASPA MARKET PULSE」を追加
- Market Pulseを日本語・英語の両方に対応
- コメントは外部AIを使用せず、取得した市場データに対する一定の判定ルールで生成
- 「クジラ集中度」を「上位100アドレス保有比率」へ変更
- 英語表記を「Top 100 Address Share」へ変更
- 残高保有アドレス欄の英語切り替え不具合を修正
- 100K+行の強調表示は使用しない

## データ更新

- 現在価格: 60秒ごと
- OI・資金調達率: 5分ごと
- 4時間足チャートとMA: 15分ごと
- 非表示タブでは更新を休止し、再表示時に即時更新

## 注意事項

OIと資金調達率はBybitのKASUSDT市場を示し、先物市場全体の集計ではありません。Market Pulseは市場データの自動要約であり、投資助言や売買シグナルではありません。

本アプリは一般公開向けです。個人の保有量、ウォレットアドレス、取得価格、損益、ポートフォリオ情報は取得・保存・表示しません。
