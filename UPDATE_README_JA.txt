KASPA LIVE BLOCKDAG v2.3.0 60秒遅延LIVE 更新パッチ

変更内容
1. BlockDAG API取得に失敗した場合、10秒ごとに自動再試行
2. 取得成功後は通常の60秒更新へ自動復帰
3. 既に取得済みデータがある場合は、再取得中も画面を維持
4. 初回取得失敗時は「データ取得待機中」と表示し、取得できるまで再試行
5. 上部集計に 1K+ / 10K+ / 100K+ / 1M+ のブロック数を表示
6. カウントは従来の100K+/1M+と同じ「しきい値以上」の累積方式

変更していないもの
- InfiniteFlightCanvas.js
- カメラ速度
- 巡航 / 引き / 俯瞰 / 旋回 / 再進入のタイミング
- 60秒遅延APIロジック

差し替え対象
- app/components/BlockDAGView.js
- app/globals.css
