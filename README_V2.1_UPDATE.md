# KASPA Holder Monitor v2.1

## 主な更新

- 価格チャートを4時間足・直近60日表示に固定
- 横スクロールを廃止し、60日分を画面幅の中へ収めて表示
- 右端の価格目盛りを独立した固定領域へ分離
- 表示中のローソク足と有効なMAに合わせて縦軸を自動調整
- 縦軸変更時のローソク足、MA、現在価格表示を約0.2秒で滑らかに追従
- 10MA（水色）、25MA（黄色）、75MA（赤）、200MA（白）を表示
- MAは日数ではなく4時間足の本数で計算（200MAは約33.3日）
- 内部では約100日分を取得し、60日表示の開始地点でもMAを正しく計算

## 自動更新

- 現在価格: 60秒ごと
- チャートとMA: 15分ごと
- 非表示タブでは更新を休止し、再表示時に即時更新
- 一時的な取得失敗時は最後に取得できたデータを保持し、更新遅延を表示

## データ方針

一般公開向けのネットワーク分析アプリです。個人の保有量、ウォレットアドレス、取得価格、損益、ポートフォリオ情報は取得・保存・表示しません。
